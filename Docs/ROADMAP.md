# Legacy of Eternity: дорожная карта

Дата актуализации: 27 ноября 2026. Владелец: LunexUfa.

## Решение по продукту (27.11.2026)

- **Основной клиент — этот репозиторий** (`C:\LegacyOfEternity`), Unity **6000.3**, Android landscape.
- `C:\SOURCE\LunexUfa` — эталон / Server-Admin / материалы переноса, не целевой клиент.
- Codex адаптирует арт-библиотеку оригинала под Unity 6 → импорт в LoE по команде владельца.
- Приёмка владельца: **APK после каждого крупного этапа**, не после каждой мелкой правки.

## Принципы

* Android-only поставка; Windows — редактор и проверки.
* Сцену `CoastalPrototype` не ломать генераторами без нужды; новые системы — runtime где возможно.
* Большие бинарники — Git LFS; APK не коммитить.
* Каждая крупная веха: код + APK/путь + запись в `Docs/CURRENT-STATUS.md`.

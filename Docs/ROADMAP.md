# Legacy of Eternity: дорожная карта

Дата актуализации: 27 ноября 2026. Владелец: LunexUfa.

## Решение по продукту (27.11.2026)

- **Основной клиент — этот репозиторий** (`C:\LegacyOfEternity`), Unity **6000.3**, Android landscape.
- `C:\SOURCE\LunexUfa` больше не целевой Android-клиент: там остаются эталон Darklord 2017, Server/Admin-лаборатория и материалы переноса. Игровой APK собираем здесь.
- Цель ближайшего среза: **оффлайн** регистрация → мир → герой (4 класса) → CoastalPrototype → квест → локальный PvE. Сеть и Go-бэкенд — после стабильного оффлайн-цикла на телефоне.

## Принципы

* Android-only поставка; Windows — редактор и проверки.
* Сцену `CoastalPrototype` и боевые ассеты не ломать генераторами без нужды; новые системы вшивать runtime-ом где возможно.
* Большие бинарники — Git LFS; APK не коммитить.
* Каждая веха: код + APK/путь + запись в `Docs/CURRENT-STATUS.md`.

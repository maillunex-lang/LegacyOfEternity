## Приёмка 0.8.0

1. Вход → герой → квест как раньше  
2. Убить монстра → тост «+Клык… / +монет»  
3. Кнопка **Сумка** (верх справа) → список предметов  
4. Собрать хлам → в сумке «Прибрежный хлам»  
5. Если есть зелье → **Выпить** (фиктивное лечение)  
6. Рестарт приложения → сумка и монеты на месте
